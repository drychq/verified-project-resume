# 接入说明

可移植核心是单一、自包含的 `skills/verified-project-resume/` 目录。

兼容的环境需要能够加载 `SKILL.md`、读写获准的本地工作目录文件，并运行 Node.js 20+ 命令。只有用户想做本地历史分析时才需要 Git；纯口述场景不需要 Git、网络或仓库。

请安装完整 Skill 目录。`agents/openai.yaml` 只是可选界面元数据，并为支持该设置的环境禁用隐式调用。建议保持显式调用：整个流程可能较长，而且简历写作必须基于记录在案的来源。

用户接口是包含 Markdown 的工作目录。`.verified-resume/records.jsonl` 是同一个已安装 Skill 使用的私有数据；针对新岗位重新定制时需要保留，但不应要求用户手工编辑。

GitHub 证据是可选的只读增强，仅在仓库在范围内时使用。若环境没有 GitHub、网络、测试、Benchmark，甚至没有 `.git`，应把来源记录为不可用或未请求，而不是解释成不存在。
