# Methodology provenance

This implementation uses an original evidence-preserving compression workflow.

- STAR supplies the full context/action/result structure.
- Action–Method–Result supplies the resume compression shape.
- `hubvue/skills` contributed the idea of interview-defensible phrasing and explicit confidence, not text or metrics: <https://github.com/hubvue/skills/tree/main/project/resume-project-analyzer>
- Agent Skills supplies the portable packaging format: <https://agentskills.io/specification>

The workflow intentionally excludes “every bullet needs a number,” conservative estimates, invented ranges, automatic leadership verbs, and reverse expansion from an existing resume bullet.
